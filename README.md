# Програмний проєкт 1 — Задача 1

Засоби функціонального програмування мови C++. Анонімні функції та
функціональні об'єкти. Three-way comparison.

Клас функціональних об'єктів генерує послідовність точок на площині:
на кожному кроці випадково вибирається одна з базових точок `b_k`, і
до поточної точки `z` застосовується перетворення `f_k(z) = (b_k + z) / 2`.

## Структура проєкту

- `point.h` / `point.cpp` — точка на площині (`operator<=>`, `operator+`, `operator/`)
- `chaos_game.h` / `chaos_game.cpp` — власний функціональний об'єкт `ChaosGame`
- `io.h` / `io.cpp` — читання вхідного файлу та запис результату
- `main.cpp` — точка входу
- `CMakeLists.txt` — конфігурація збірки (C++23)

## Формат вхідного файлу (`input.txt`)

```
n
x0 y0
b1x b1y
b2x b2y
...
```

- `n` — скільки точок згенерувати
- `x0 y0` — початкова точка
- далі — базові точки (хоча б одна), по одній на рядок

## Формат результуючого файлу (`output.txt`)

По одній згенерованій точці на рядок: `x y`.

## Збірка та запуск

```
cmake -S . -B build
cmake --build build
./build/Debug/proj1.exe input.txt output.txt
```
